# mini-alphafold

A small-scale, educational re-implementation of DeepMind's AlphaFold2 for protein structure prediction.

**Goal**: Learn modern deep learning for biology by building a functional (but simplified) protein folding model.

## Project Phases

- **Phase 0**: Data pipeline & tokenization
- **Phase 1**: Sequence modeling (secondary structure, contact maps)
- **Phase 2**: End-to-end coarse 3D structure prediction
- **Phase 3**: MSA integration + attention improvements

## Tech Stack
- PyTorch
- Hugging Face Datasets / Transformers
- Biopython / Prody (for structure handling)
